# Project Documentation Rules / 项目文档规则

- The README must always be provided in both English and Simplified Chinese.
- README 必须始终同时提供英文和简体中文版本。
- Every GitHub Release title and description must be understandable to both English- and Chinese-speaking users. The release body must contain complete English and Simplified Chinese sections with equivalent information.
- 每个 GitHub Release 的标题和说明必须让中英文用户都能理解。Release 正文必须包含信息对等、内容完整的英文和简体中文部分。
- Download instructions, feature lists, upgrade notes, warnings, checksums, and known limitations in public release documentation must be bilingual.
- 公开发布文档中的下载说明、功能列表、升级说明、警告、校验值和已知限制必须使用中英双语。
- Do not remove one language while editing the other. Keep both versions synchronized in the same change.
- 修改其中一种语言时不得删除另一种语言；同一次修改必须同步更新两个版本。
