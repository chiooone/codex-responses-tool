# 项目文档规则 / Project Documentation Rules

## 中文规则

- README 必须始终同时提供简体中文和英文版本。
- 所有中英双语公开文档必须采用“中文在前、英文在后”的顺序。
- GitHub Release 的标题和正文必须让中英文用户都能理解；Release 正文必须先提供完整的简体中文内容，再提供信息对等的完整英文内容。
- 公开发布文档中的下载说明、功能列表、升级说明、警告、校验值和已知限制必须使用中英双语。
- 修改其中一种语言时不得删除另一种语言；同一次修改必须同步更新两个版本。

## English rules

- The README must always be provided in both Simplified Chinese and English.
- All public bilingual documentation must place Chinese first and English second.
- Every GitHub Release title and description must be understandable to both Chinese- and English-speaking users. The release body must contain a complete Simplified Chinese section first, followed by a complete English section with equivalent information.
- Download instructions, feature lists, upgrade notes, warnings, checksums, and known limitations in public release documentation must be bilingual.
- Do not remove one language while editing the other. Keep both versions synchronized in the same change.
